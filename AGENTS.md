# Agents overlay

For any implementer, human or automated:

1. Read RESUME.md and the latest records/ before writing; after any interruption, reread them.
2. Work packet by packet; judge each by its acceptance command (plan/packets.csv, accepted_when).
3. Read a tool's --help or source before driving it (GOV-15).
4. Record every run (repsynth/records.py), write reports/status/<packet>.json and reports/completion/<packet>.md.
5. Name no AI as author or contributor anywhere in the tree.
