# Context overlay

hmnsq/repsynth is the harness of package repsynth 0.3.0: one specification per representation; generated inputs
for QEMU, GNU binutils and GCC, hardware simulators and synthesis, APCISR; kept containers; one set of vectors
for every target; exact regeneration of what a change touches. It complements paras, Parashakti and SHAKTI
(document 00, the Sovereignty Architecture). Binary is the performance baseline; balanced ternary is the
representation-change demonstrator (RD5).
